# Legacy Tree

`src/legacy` is retained for reference only. It is not the packaged application path and should not be treated as the supported entrypoint for the current codebase.

Use these entrypoints instead:

- `madd` for the active CLI
- `madd-ui` for the browser-based scenario studio

The legacy code here preserves an older implementation of the debate flow, prompts, and supporting utilities. Keep it as reference material unless you are explicitly working on migration or archival cleanup.

If you are looking for the current implementation, start in `src/madd/`.
